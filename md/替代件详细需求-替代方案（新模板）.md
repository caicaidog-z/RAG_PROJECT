# 业务规则

- 组合替代说明：
  - 统一替代组号内的多个替代件共同替代多个主件。
    - 统一替代组内的优先一致；
    - 一个替代组内有且只有一个关键件。
- 替代方案保存校验：
  - 替代方案中的主件明细行和替代件明细需要至少各存在一行明细；
  - 替代件和主件不能重复（物料编码+属性）
  - 不同优先级的替代件之间不能重复（物料编码+属性）
- 半成品替代校验：
  - 若补货策略为补充主件，无校验
  - 若补货策略为补充替代件时，替代方案保存时，替代件明细中的物料是否勾选采购属性，若未勾选弹窗提示，禁止保存
    - 对于替代方案保存后，后续调整物料用途，在计划运算时，由于运算参数等原因，导致替代物料按照自制或委外用途生成对应计划时，固定按照补充主件进行运算，运算说明增加相关提示
      - 按照替代件优先级逐级检查，若所有替代件都无法采购，则采购主件【开发待定】
  - 在BOM引用替代方案保存时，循环引用校验
- 替代方案停用：
  - 停用后的替代方案，不可再继续使用，已经引用的单据在进行MRP运算时也作为没有替代件进行运算。
- 替代方案 支持获取替代件的现存量和可用量
  - 同通用可用量提取规则相同，可用量维度仅支持物料+属性

# 选项

- 选项名称：
  - 是否启用替代件管理
    - 是
    - 否
- 默认值
  - 默认不启用
- 位置：
  - 工程数据下最后一项
- 业务规则：
  - 启用替代件管理后，显示替代方案菜单，露出替代件相关默认字段
  - 反启用替代件管理后，隐藏替代方案菜单，隐藏替代件相关默认字段
    - 不存在替代方案（含物料清单设置的自定义替代方案）时，支持反启用

- 选项名称
  - 出库单是否支持替代（随时可修改）
    - 是
    - 否
- 默认值
  - 默认不支持
- 位置：
  - 工程数据
    - 是否启用替代件管理之后
- 业务规则：
  - 启用出库单支持替代后，材料出库单和委外发料单支持设置替代件
  - 支持随时反启用
    - 反启用后，出库单不再支持设置替代件，历史单据不支持修改替代件（可以修改数量，不支持增加新的替代件行和删除替代件行），固定按照加工单设置的替代出库
